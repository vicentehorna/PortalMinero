Procesar documentos del servidor

Esta acción leerá los PDF de una carpeta de Google Drive y sincronizará su metadata en la base de datos.

ID de carpeta de Google Drive configurado: {% if ruta_servidor %} {{ ruta_servidor }} {% else %} Sin carpeta configurada. {% endif %}

La ruta se toma de Configuración por usuario. {% if not ruta_servidor %} Debe guardar allí un ID de carpeta de Google Drive válido antes de sincronizar. {% endif %}

Formato esperado del nombre: Tipo_Periodo_DNI_Nombre empleado.pdf (separado por guiones bajos; el nombre puede incluir espacios si no hay más guiones bajos). Los archivos con FIN_DE_MES en el nombre se renombran automáticamente a BOL_Periodo_DNI_Nombre.pdf antes de sincronizar. Se incluyen PDF en subcarpetas (por ejemplo BOLETA/2026). La carpeta debe estar compartida con la service account de Render como Editor.

Si la sincronización se corta a mitad (miles de PDF)

En el servidor el proceso puede tardar varios minutos. Si se interrumpe, los documentos ya guardados permanecen: pulse de nuevo Sincronizar para continuar. Referencia de soporte: SYNC_TIMEOUT.

Si falla la conexión con Google (timeout o error de red)
  • Antivirus de terceros (Avast, AVG, McAfee, Kaspersky, etc.): suelen inspeccionar o bloquear el tráfico HTTPS de python.exe. Solución habitual: añadir excepción para el ejecutable de Python que usa el portal, o permitir conexiones salientes a *.googleapis.com y oauth2.googleapis.com, sin desactivar todo el antivirus.
  • Firewall de Windows: permita la aplicación Python (o el servicio que hospeda Flask) en redes privadas/de trabajo si aplica.
  • Oficina con proxy: el administrador debe configurar el proxy en el servidor (variables de entorno HTTPS_PROXY / HTTP_PROXY) para que Python pueda salir a Internet.
  • El bloqueo ocurre en la máquina donde corre la aplicación (servidor o su PC si ejecuta Flask ahí), no solo en el navegador.
